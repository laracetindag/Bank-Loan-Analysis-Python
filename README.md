# Bank-Loan-Analysis-Python
Python data analysis project exploring bank loan applications, funding trends and borrower characteristics.
## Problem statement

The bank needed to analyse its loan portfolio to better understand lending performance, loan repayments and borrower characteristics. The project focused on two main areas:

### 1. Loan portfolio performance

The analysis aimed to calculate five financial KPIs:

- **Total Loan Applications:** Measure the number of loan applications received.
- **Total Funded Amount:** Calculate the total value of loans issued.
- **Total Amount Received:** Track repayments received from borrowers.
- **Average Interest Rate:** Determine the average interest rate across the loan portfolio.
- **Average Debt-to-Income Ratio (DTI):** Assess borrowers' financial obligations relative to their income.

The project also required month-to-date (MTD) reporting for loan applications, funded amounts and repayments.

Loan applications were classified as **good or bad loans** to compare application volumes, percentages, funded amounts and repayments between the two categories.

### 2. Lending trends and borrower analysis

The project required visualisations to examine:

- **Monthly lending trends:** Identify changes in loan activity over time.
- **Regional performance:** Compare lending activity across states.
- **Loan terms:** Analyse the distribution of loans across different repayment periods.
- **Employment length:** Examine lending activity based on borrowers' employment history.
- **Loan purpose:** Identify the main reasons borrowers applied for loans.
- **Home ownership:** Compare lending activity across different home-ownership categories.

The objective was to provide a clearer understanding of the bank's lending activity, repayment performance and loan distribution to support financial and risk management decisions.
